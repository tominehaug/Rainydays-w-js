# Rainydays with JavaScript

![image](https://user-images.githubusercontent.com/52622303/164316813-4b12d99f-aeb7-4069-85cf-e72b3a50ac99.png)

Online store for rain jackets! It is the product of a cross course project from my first semester of Front-End Development studies at Noroff Vocational School, further extended with JavaScript in my introductory JavaScript course the second semester.

## Description

Design, HTML and CSS from earlier courses. Added JavaScript includes following features:

- API calls
- Events

The purpose with this project was to practice:
- Understanding Document Object Model (DOM) and using that to influence structure, content and design in HTML documents
- Methods for API calls
- JavaScript Events
- Developing interactive and dynamic web solutions
- JavaScript syntax and structure
- Debugging JavaScript

## Technologies

- JavaScript
- HTML
- CSS
- ESLint
- Prettier
